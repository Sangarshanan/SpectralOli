Getting Started

SpectralOli is a real-time browser-based spectral livecoding environment. Load one or more loops, write DSL expressions per track, and sculpt sound by shaping frequency regions, time behavior, blur, and granulation.

Quick Start

  • Upload audio with Upload audio or search with Query Freesound.
  • Press Play All to start transport and spectral processing.
  • Type a DSL expression in a track code box and apply with Ctrl+Enter on Windows/Linux or Cmd+Enter on macOS.
  • Adjust BPM and beats to change the global cycle all loops follow.

Chains evaluate left to right. A region expression becomes a magnitude multiplier per spectral bin.

Environment Setup

fft(size) sets the FFT frame size used for spectral analysis on a track. Must be a power of two between 256 and 8192, and if used, must be the very first statement in the track's code, before any expression. Defaults to 1024 when omitted.

Smaller sizes give faster time resolution (good for percussive/granular material); larger sizes give finer frequency resolution (good for tonal/harmonic material).


fft(2048)
band(200, 4000)

Spectral Blur

.blur(freq_amt, time_amt) smears spectrum in frequency and time. Both args are optional and default to 0.5.


blur(0.8, 0)
blur(0, 0.85)
blur(0.3, 0.6)
blur(Math.sin(time * 0.25) * 0.25 + 0.5, 0.6)
band(200, 4000).blur(0.5, 0.4)

Spectral Scale, Rotate, Skew & Transpose

These treat the spectrogram as a 2D canvas (time on the X axis, frequency on the Y axis) and warp it directly.

CallBehavior
.scale(x_stretch, y_stretch, mix)X: time-stretch factor (1 normal, 2 half speed). Y: frequency inharmonicity factor, stretching spacing between bins. Defaults: 1, 1, 1
.rotate(degrees, mix)blends X and Y axes, skewing time into frequency and vice versa. Defaults: 0, 1
.skew(x_skew, y_skew, mix)locks one axis in place and progressively slides the other, creating a slanted parallelogram. Defaults: 0, 0, 1
.transpose(mix)reflects the matrix across its main diagonal — time and frequency axes are fully swapped (x' = y, y' = x). Default: 1

X-Axis Skew (Time offset by Frequency): Forces high frequencies to play slightly later (or earlier) than low ones. Sonic Equivalent: Spectral Delay, Dispersion (like Ableton's Spectral Time "Tilt" or dropping a rock on a frozen lake).

Y-Axis Skew (Frequency offset by Time): The longer a sound plays on the X-axis, the further its pitch gets shifted on the Y-axis. Sonic Equivalent: Continuous Glissando, endless pitch-riser, or slow Tape-Stop effect.

Transpose: The most radical pure affine transformation. The spectrogram is flipped on its side — the loop's temporal length literally becomes frequency bandwidth. Sub-bass energy becomes an immediate transient burst. An evolving 4-second pad becomes a 4-second frequency sweep.


// Time-stretch by 2x (X-axis) without altering pitch (Y-axis)
band(200, 8000).scale(2, 1, 1)

// Stretch harmonic ratios by 1.5x (Y-axis) to create inharmonic, metallic bells
band(100, 4000).scale(1, 1.5, 1)

// Rhythmic rotation: spins the matrix forward over time, 80% wet
low(5000).rotate(time * 45 % 360, 0.8)

// X-Axis Skew: smear frequencies across time (pew-pew dispersion)
band(200, 8000).skew(0.5, 0, 1)

// Y-Axis Skew: endless pitch-riser (continuous glissando)
band(200, 8000).skew(0, 0.5, 1)

// Transpose: turn sub-bass energy into a transient burst, pads into frequency sweeps
band(20, 20000).transpose(1)

// Transpose at 50% wet -- blended with original for a ghostly mirrored texture
band(20, 20000).transpose(0.5)

SlicePattern DSL (v3)

The SlicePattern DSL allows you to automatically slice, sequence, and transform audio regions using concise slice-spec strings and method chaining. Patterns are pure immutable arrays where operations transform targeted steps without altering the timing or order of untargeted steps. You can chain any spectral filtering, time modification, or matrix transformation directly onto pattern statements!

Automatic Slicing Commands

These prefix statements automatically slice the track and update the visual slice editor, identical to clicking the Detect button. They must appear before seq().

CommandBehavior
slicep(fftSize)Percussive onset detection. Uses high-frequency energy to find drum hits and transients. fftSize must be a power of 2 between 256–8192.
slicem(fftSize)Melodic onset detection. Uses spectral flux to find harmonic changes and note onsets. fftSize must be a power of 2 between 256–8192.
slicee(N)Equal-width slicing. Divides the full audio buffer into N equal-length chunks regardless of content.

Slice-Spec Grammar

A spec is a comma-separated list of ranges (start:stop) or single indices (negative numbers count from the end):

Spec ExampleBehavior & Selection
"2"selects slice index 2
"2:5"selects slice indices 2, 3, 4 (stop is exclusive, like Python slicing)
":4"selects from start up to index 4 (indices 0, 1, 2, 3)
"6:"selects from index 6 to the end of the pattern/buffer
"-4:"selects the last 4 slices in the pattern/buffer
":2, 2:5, 6:"concatenates multiple range selections in written order

Pattern Core Methods

MethodDescription
seq(spec?)Generates a sequence of steps from the current track slices. With no arguments, returns all slices in order (0..N-1). With a spec, emits steps in the written order. Can be chained with any spectral method.
at(spec, operation, prob = 1.0)(Alias: within) Targets steps by their Timeline Step Position (indices 0..L-1). Applies the operation to the targeted segment. Optional prob (0 to 1) applies it probabilistically.
on(spec, operation, prob = 1.0)Targets steps by their underlying Audio Slice ID (matches sliceIndex). Applies the operation to the targeted segment wherever those slices appear in the sequence. Optional prob (0 to 1) applies it probabilistically.

Pattern Operations

OperationBehavior
stutter(count, gap = 0)Repeats each targeted step count times within its time slot. gap (0 to 0.95) inserts silence between repeats.
reverse()Plays each targeted step's audio sample window backwards in real time without altering sequence order.
shuffle()Randomly permutes the targeted steps among themselves while untargeted steps stay fixed.
silence()Mutes targeted steps (outputs clean silence for the slice's natural duration, acting as a true musical rest without deleting time).
repeat(n)Loops the entire targeted block n times within that block's original duration.
 

// Play all slices sequentially (slices must already exist via UI or sliceX command)
seq()

// Play slices 0–3, then 6 onwards
seq(":4, 6:")

// Auto-slice percussively, then sequence all slices
slicep(512)
seq()

// Auto-slice melodically, then sequence with timeline-based (at) operations
slicem(1024)
seq()
  .at("0", stutter(2))
  .at("2:4", stutter(5))

// Equal-width slice into 16 chunks, silence chunk 8 with 80% probability
slicee(16)
seq().at("8", silence(), 0.8)

// Target by underlying Audio Slice ID rather than step position (on)
slicep(512)
seq(":10, :10, 10:")  // Plays slices 0-9 twice, then 10+
  .on("0:4", reverse())  // Reverses slices 0-3 wherever they appear in the timeline (both repetitions!)
  .at("0:10", shuffle())  // Shuffles only the first repetition (timeline steps 0-9)

// Chain spectral filters and speed modifications directly onto a slice pattern
seq(":4, 6:").band(200, 4000).fast(2)

// Probabilistically reverse slices in the second half of the sequence with a 50% chance per step
seq().at("4:", reverse(), 0.5)
